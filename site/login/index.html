로그인

Google로 로그인해 계정과 활동 대시보드를 여세요. 각 기기는 로컬 전용으로 시작하며, 연결만으로 업로드에 동의한 것은 아닙니다.

Google로 계속하기 →

Google이 자체 화면에서 동의를 요청합니다. skillar는 Google ID, 이메일, 이름, 사진과 최초·최근 로그인 시각을 저장합니다. 세션은 서명된 보안 쿠키로 유지하며 Google 토큰은 보관하지 않습니다.

MCP 연결 방법 보기 →

계정에서 에이전트까지

대시보드에서 기기를 연결하고 업로드 동의를 선택한 뒤 세션, 작업 공간, 사용 흐름과 활동 분포에서 기록을 확인하세요.

에이전트를 내 비공개 스킬에 연결하려면 MCP 연결을 이용하세요. 요금은 아직 발표되지 않았습니다.
