# skillar landing

Static Vite site for Cloudflare Pages. No backend, signup collection, external fonts, analytics, or custom-domain binding.

```sh
cd site
npm ci
npm run build
npm run preview
```

Pages project: `skillar-site`. Build command: `npm run build` from `site`; output: `site/dist`. Deploy `feat/landing` as a preview, never attach `skillar.sh` without the owner's decision.

`public/workshop.webp` is an optimized copy of the repository's own `docs/assets/gisul-workshop.png`. See that folder's README for source details. The code example excerpts `plugins/skillar/skills/skillar/SKILL.md`, with its complete frontmatter and first instruction sentence.

Product claims are sourced from the root README, `local/README.md`, `server/README.md`, `worker/src/`, and `docs/deployment.md`. Managed signup, provisioning, and hosted prices are explicitly coming soon. Local privacy does not imply hosted privacy.
