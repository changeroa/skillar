Connect an agent with OAuth.

Add the endpoint below to your agent as a remote HTTP MCP server. The agent opens skillar's approval page in your browser, where you sign in with Google and allow read access; no credential is typed or copied here. Your browser's sign-in cookie and device connector tokens are never MCP credentials.

Endpoint
Permission
Read private skills (skills:read). No connection can change, publish or delete a skill.
Recording
Off unless you also allow activity:record on the approval page.

Claude Code

claude mcp add --transport http skillar

JSON client configuration (mcpServers)

{
  "mcpServers": {
    "skillar": { "type": "http", "url": "" }
  }
}

Codex and other clients name this differently; use their remote HTTP MCP option with the same URL. When the agent asks you to sign in, approve read access in the browser window it opens. The approval appears in the list below as an OAuth connection.

Create a personal access token.

For agents that can't open a browser. The token is shown once, right after you create it; skillar keeps only a hash, so it can't be shown again. It expires after the days you choose, at most 30, and you can revoke it below at any time.

    Your new token. Shown once.

    Copy it into your agent now. Once you dismiss it, it is gone from this page and can't be shown again; create another token if you lose it.

    Agents send it as Authorization: Bearer <token>. Claude Code: claude mcp add --transport http skillar --header "Authorization: Bearer <token>"
