Google로 계속하기 →

로그인 후 이 화면으로 돌아옵니다. Google이 자체 화면에서 동의를 요청하며, skillar는 Google ID, 이메일, 이름, 사진과 최초·최근 로그인 시각을 저장합니다. 세션은 서명된 보안 쿠키로 유지하고 Google 토큰은 보관하지 않습니다.

이 배포에서는 아직 MCP 연결을 이용할 수 없습니다. 발급된 것은 없으며 이 화면의 내용도 저장되지 않습니다.

MCP 연결 명령

claude mcp add --transport http skillar
OAuth 연결 안내와 클라이언트 설정

아래 주소를 에이전트의 원격 HTTP MCP 서버로 추가하세요. 에이전트가 브라우저에서 skillar 승인 화면을 열면 Google로 로그인하고 읽기를 허용합니다. 이곳에서 인증 정보를 입력하거나 복사하지 않습니다. 브라우저 로그인 쿠키와 기기 연결 토큰은 MCP 인증 정보가 아닙니다.

서버 주소
권한
비공개 스킬 읽기(skills:read). 연결은 스킬을 수정·게시·삭제할 수 없습니다.
활동 기록
승인 화면에서 activity:record도 허용하기 전에는 꺼져 있습니다.

Claude Code

claude mcp add --transport http skillar

JSON 클라이언트 설정 (mcpServers)

{
  "mcpServers": {
    "skillar": { "type": "http", "url": "" }
  }
}

클라이언트마다 설정 이름이 다를 수 있습니다. Codex 등의 원격 HTTP MCP 옵션에 같은 URL을 사용하세요. 에이전트가 로그인을 요청하면 열린 브라우저에서 읽기를 허용하세요. 승인한 항목은 아래 목록에 OAuth 연결로 표시됩니다.

개인 액세스 토큰 만들기

브라우저를 열 수 없는 에이전트를 위한 토큰입니다. 생성 직후 한 번만 표시되며, skillar는 해시만 저장하므로 다시 볼 수 없습니다. 선택한 기간(최대 30일) 후 만료되며 아래에서 언제든 해제할 수 있습니다.

    새 토큰 · 한 번만 표시

    지금 에이전트에 복사하세요. 닫으면 이 화면에서 사라지고 다시 표시할 수 없습니다. 잃어버린 경우 새 토큰을 만드세요.

    에이전트는 다음 헤더로 전송합니다: Authorization: Bearer <token>. Claude Code: claude mcp add --transport http skillar --header "Authorization: Bearer <token>"
