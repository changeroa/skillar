Good questions.

What is an agent skill?

A folder containing a SKILL.md instruction file and optional supporting files. The name and description help an agent discover it; the body carries the actual instructions.

Can I use skillar today?

Yes. Install the local CLI with npm install -g skillar. Run skillar init --dry-run to preview setup changes. macOS or Linux and Node.js 24.15+ are required. If you are upgrading from gisool, read the migration guide first.

Is the hosted service live?

Not yet. Signup, managed server provisioning, and hosted pricing are coming soon. This preview does not create an account or collect your email.

Does every MCP client work?

Skills require a host that can discover and read MCP resources. The repository includes runtime-specific integrations; compatibility and capture coverage vary. Check the protocol and compatibility guide for your client.

Where does my local data go?

The local daemon listens on loopback, uses a local bearer token, and stores indexed skills and captured session activity in local SQLite. It does not upload captured telemetry. Your connected agent and model provider handle data separately.

Can I host a registry for my team?

Yes. The repository includes a Node.js registry and a Cloudflare Worker for authenticated distribution from private R2 releases. You provide infrastructure and credentials. See the deployment guide.
