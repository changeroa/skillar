예시 데이터

배포 전 변경 사항 검토

설명을 위한 가상 세션 · 실제 계정 기록이 아닙니다.

  1. 세션 요청

    “배포 전에 변경 사항과 확인할 항목을 정리해 줘.”

  2. 검색 → 버전 읽기

    deploy-checklist / SKILL.md · v3

    배포 점검 지침을 읽은 이벤트

  3. 읽은 뒤의 기록

    변경 사항을 요약하고 확인할 항목을 작성했습니다.

    작업 성공 여부: 평가 안 됨

이 예시는 흐름을 설명하는 정적 데이터입니다. 버전 연결과 후속 결과의 표시 범위는 수집된 기록에 따라 다릅니다. 읽기는 적용이나 성공의 증거가 아닙니다.

기록을 읽는 세 가지 관점

스킬 목록에서 끝나지 않는 근거.

  1. 트레이스

    세션에서 어떤 스킬을 읽었는지 살펴보세요. 읽기 이벤트와 이후 기록을 구분하면 무엇을 확인해야 할지 보입니다.

  2. 측정되는 검색

    검색어, 후보와 읽기 기록을 함께 검토하세요. 검색 결과에 나타난 것과 실제로 읽은 것은 다릅니다.

  3. 근거와 함께 공유

    판단에 사용한 세션과 버전을 짚어 설명하세요. 공개 증거 링크와 팀 공유 기능은 아직 제공하지 않습니다.

문서와 MCP

연결 전에 범위를 확인하세요.

로컬 기록은 내 기기에 남습니다. 호스팅 대시보드에 업로드하려면 기기 연결 후 기록 범위에 별도로 동의해야 합니다.

설정과 기록 범위 문서 읽기 ↗ MCP 연결 방법 보기 →

호스팅 MCP를 이용할 수 있습니다. OAuth 또는 읽기 전용 토큰으로 게시한 비공개 스킬에 접근합니다. 연결만으로 기기 업로드나 MCP 활동 기록에 동의하지 않습니다.

로컬에서 시작하려면 npm install -g skillar, skillar init --dry-run으로 변경 내용을 먼저 확인하세요.
