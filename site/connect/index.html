연결

클라이언트의 원격 HTTP MCP 서버로 https://skillar.sh/mcp를 사용하세요. 로그인한 계정에 직접 게시한 비공개 스킬만 읽습니다.

OAuth를 사용하면 클라이언트가 Google 로그인과 승인 절차를 엽니다. 브라우저를 열 수 없다면 연결 화면에서 읽기 전용 개인 액세스 토큰을 만드세요. Google 쿠키와 기기 연결 인증 정보는 MCP 토큰이 아닙니다.
